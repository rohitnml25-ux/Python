About the project

Problem statement

  • Manual banking record keeping is slow and error-prone.
  • Each customer needs a unique account number.
  • The system must support account creation, deposits, withdrawals and transfers.
  • It must keep a transaction history and reject invalid transactions such as insufficient balance.

Objectives

  • Create accounts with unique account numbers.
  • Deposit, withdraw and transfer funds securely.
  • View balances and a complete transaction history.
  • Store and retrieve data using file handling.

Algorithm

  1. Open the account file or database.
  2. Choose an operation.
  3. Validate the account number and amount.
  4. Update the balance and the transaction history.
  5. Display the result or an error.

Python concepts used

  • Control structures and menu loop
  • Dictionaries and lists
  • Functions and exceptions
  • pandas for the CSV statement
  • File handling (JSON) and OOP

Core Python logic

class Account:
    def withdraw(self, amount, kind="Withdraw"):
        if amount <= 0:
            raise ValueError("Amount must be positive")
        if amount > self.balance:
            raise InsufficientBalance("Insufficient Balance")
        self.balance -= amount
        self._log(kind, amount)

def transfer(self, src, dst, amount):
    a, b = self.get(src), self.get(dst)
    a.withdraw(amount, "Transfer Out")   # raises before anything changes
    b.deposit(amount, "Transfer In")
    self.save()
